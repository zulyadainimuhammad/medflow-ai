# Contributing to MedFlow AI

Thank you for helping improve MedFlow AI.

## Development Workflow
1. Create a branch from main using a descriptive name.
2. Keep changes small, focused, and testable.
3. Include documentation updates for behavior or API changes.
4. Open a pull request using the project template.

## Commit Standards
- Use clear, imperative commit messages.
- Reference related issues in commit or PR descriptions.
- Avoid bundling unrelated changes.

## Quality Gates
- Run linters and tests before opening a PR.
- Ensure security-sensitive code paths include tests.
- Include migration notes when database changes are introduced.

## Pull Request Requirements
- Problem statement and proposed solution.
- Test evidence and risk assessment.
- Rollback strategy for operationally significant changes.

## Compliance and Data Safety
Do not commit protected health information (PHI), credentials, or secrets.
