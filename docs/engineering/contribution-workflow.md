# Contribution Workflow - Template

## 1. Purpose
Define the end-to-end workflow for proposing, implementing, reviewing, and merging changes.

## 2. Intake and Planning
- Create/triage issue
- Define acceptance criteria
- Link to roadmap and architecture docs

## 3. Branch and Commit Workflow
- Branch naming convention
- Commit message convention
- Rebase/merge strategy

## 4. Pull Request Workflow
- Required PR sections
- Required evidence (tests, screenshots, logs)
- Risk and rollback statement

## 5. Review Process
- Reviewer roles
- SLA expectations
- Approval requirements
- Conflict resolution path

## 6. Quality and Compliance Gates
- CI checks
- Security checks
- Documentation updates
- Regulatory/compliance review where applicable

## 7. Merge and Release
- Merge strategy
- Release note/changelog updates
- Post-merge verification

## 8. Post-Release Feedback
- Monitor impact metrics
- Capture lessons learned
- Feed back into roadmap and ADRs
