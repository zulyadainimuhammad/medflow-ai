# Architecture Decision Records (ADR) Index

This index tracks accepted and proposed architecture decisions for MedFlow AI.

## Naming Convention
- File format: `adr-XXXX-short-title.md`
- IDs increment sequentially.

## Status Definitions
- Proposed: Draft under review.
- Accepted: Approved and active.
- Superseded: Replaced by a newer ADR.
- Rejected: Reviewed but not adopted.
