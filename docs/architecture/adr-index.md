# Architecture Decision Records (ADR) Index

Use this index to track architecture decisions in chronological order.

## Naming Convention
- File format: `adr-XXXX-short-title.md`
- Example: `adr-0001-use-event-driven-integration.md`

## Status Definitions
- Proposed: Draft under review.
- Accepted: Approved and active.
- Superseded: Replaced by a newer ADR.
- Rejected: Not adopted.
