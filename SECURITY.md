# Security Policy

## Supported Versions
This repository is in scaffold phase. Security support policy will be finalized before first production release.

## Reporting a Vulnerability
Please report vulnerabilities privately to: security@medflow.ai (placeholder)

Include:
- Affected component and version/commit.
- Reproduction steps or proof-of-concept.
- Impact assessment and potential exploitability.

## Response Process
- Acknowledge report within 3 business days.
- Validate and triage severity.
- Coordinate remediation and disclosure timeline.
- Publish security advisory when appropriate.

## Secrets Management
Never commit secrets. Use secure secret managers and environment-specific credentials.
